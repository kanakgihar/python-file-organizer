# Python File Organizer Automation

## Project Overview

This project is a Python automation script that automatically:

- Sorts files into folders
- Renames files using timestamps
- Creates folders automatically
- Maintains a log file
- Handles errors properly

The script helps automate repetitive file management tasks.

---

# Features

✅ File Handling (Read/Write)

✅ File Sorting by Extension

✅ Automatic File Renaming

✅ Folder Creation

✅ Error Handling

✅ Logging System
